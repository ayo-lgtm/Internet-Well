# Internet-Well v0.5.0 — Reliable Execution and Product Systems

## Release summary

v0.5.0 consolidates the post-v0.4 Agent Brain work into a reviewed developer-
preview release. It adds governed compliance and knowledge adapters, agent
reliability evaluation, durable execution orchestration, autonomous-
engineering planning, storeless PWA guidance, and a complete brand/design-
system capability bundle.

## Major additions

- Agent Reliability scenarios, evidence gates, trajectory tracing, governed
  production-agent sources, and a packaged CLI.
- Closed-loop execution orchestration with explicit adapter contracts,
  budgets, authorization gates, retries, stop conditions, and recovery.
- Governed Probo SOC 2 readiness and structured-knowledge discovery adapters.
- Autonomous-engineering planning and supervised multi-role execution models.
- Storeless PWA, iPhone notification, backend-stage, and free/open stack
  guidance.
- Governed brand identity, typography, iconography, color, design-token,
  asset-manifest, and component-documentation resources.
- CI enforcement preventing empty registry categories or required Founder OS
  surfaces.

## Open-source release hardening

- Explicit Apache-2.0 and CC-BY-4.0 path boundaries are documented in
  `LICENSES.md`, with the content-license notice in `LICENSE-CONTENT`.
- Public-tree and complete-history secret checks run in CI without printing
  suspected credential values.
- Required branch-protection contexts use unique GitHub check names.
- The release package includes both applicable first-party license notices.

## Compatibility

The existing v0.4 CLI commands remain available. Newer reliability,
orchestration, compliance, knowledge, agent-system, Apple-design, screenshot,
Ponytail, and Agent Brain commands are included in the package.

Internet-Well remains a supervised developer preview. It does not grant
production-write authority, certify security or compliance, provide legal or
financial advice, or authorize live trading.

## Verification

The release candidate must pass registry and Founder OS validation, public
tree and Git-history hygiene, all unit and integration suites, Agent Brain
evaluation, package build, clean-environment wheel installation, CLI smoke
tests, and the complete GitHub Actions matrix.
