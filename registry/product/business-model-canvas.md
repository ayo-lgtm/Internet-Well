# Business Model Canvas — one-page business model articulation

## What it does
The standard one-page framework for articulating a business model:
customer segments, value propositions, channels, relationships, revenue
streams, key resources/activities/partners, cost structure. Forces a
founder to state the whole model explicitly and see which boxes are
assumptions.

## When to use
- Before building: fill it in, mark every box as fact vs assumption,
  and treat assumption boxes as the riskiest-first test list
- Revisit at each pivot/pricing change; keep dated versions in git as a
  strategy decision record alongside MADRs

## Installation
Download the official PDF; or reproduce the nine blocks as Markdown in
your strategy repo (with attribution) for versionable, agent-readable
form.

## Agent integration
A Markdown canvas is excellent agent grounding: agents can flag
untested assumptions, inconsistencies (e.g. cost structure vs revenue
model), and drift between canvas and shipped product — analysis for
human judgment, not decisions.

## Required human review
All strategic content; the canvas structures thinking, nothing more.
