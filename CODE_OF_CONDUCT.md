# Code of Conduct

Internet-Well welcomes constructive participation from people with different backgrounds and levels of experience.

Contributors are expected to communicate professionally, critique ideas rather than people, respect privacy and confidentiality, avoid harassment or discriminatory conduct, and follow repository security and disclosure rules.

Unacceptable behavior includes harassment, threats, doxxing, publishing another person's private information, deliberately exposing credentials or confidential repository data, spam, or repeated disruptive behavior after a maintainer request to stop.

Project maintainers may edit or remove contributions, comments, issues, or participation that violate these expectations. Serious security or privacy concerns should be reported privately using the process in `SECURITY.md` rather than posted publicly.

Questions about moderation may be raised with the repository owner through an appropriate private GitHub channel.
