# Commands

Commands are task-oriented entry points. Select one before browsing resources.

| Goal | Command |
|---|---|
| Understand a project and its risks | `assess-project.md` |
| Choose tools, standards, or reference implementations | `select-resources.md` |
| Add a selected resource to a target repository | `adopt-resource.md` |
| Review an existing product | `audit-product.md` |
| Prepare a product for release | `prepare-launch.md` |
| Model stakeholder reactions and scenarios | `simulate-decision.md` |

Every command must produce traceable outputs and preserve the authority rules in `AGENTS.md`.
