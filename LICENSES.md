# Internet-Well licensing scope

Internet-Well uses separate licenses for executable materials and original
human-readable content. This file controls when a file does not contain a
more specific license notice.

| Material | Controlling license |
|---|---|
| Python source in `internet_well.py`, `automation/`, and `tests/` | Apache License 2.0 (`LICENSE`) |
| Executable and machine-readable configuration in `.github/`, `bundles/`, `catalog/`, `integrations/`, `outputs/`, `schemas/`, and `templates/` | Apache License 2.0 (`LICENSE`) |
| `pyproject.toml`, `VERSION`, and other build or packaging configuration | Apache License 2.0 (`LICENSE`) |
| Original Markdown and other human-readable prose, including `registry/`, `docs/`, `governance/`, `playbooks/`, `profiles/`, `stacks/`, `commands/`, `capabilities/`, `connections/`, `evidence/`, `evaluations/`, `examples/`, `skills/`, `workflows/`, and top-level project documentation | CC-BY-4.0 (`LICENSE-CONTENT`) |
| Human-readable README files within otherwise Apache-licensed directories | CC-BY-4.0 (`LICENSE-CONTENT`) |
| A file carrying its own explicit SPDX or license notice | That file-specific notice |
| Third-party names, descriptions, quotations, data, links, and referenced resources | The applicable third-party rights and terms; catalog inclusion does not relicense them |

Registry `license` fields describe the upstream resource being cataloged.
They do not replace the CC-BY-4.0 license governing Internet-Well's original
registry description.
