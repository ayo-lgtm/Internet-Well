# Security Policy

## Supported version

The latest tagged public-preview release and the current `main` branch receive security fixes.

## Reporting a vulnerability

Do not open a public issue containing a vulnerability, private repository finding, credential, personal data, exploit details, or confidential architecture. Use GitHub's private vulnerability reporting feature for this repository. Include the affected version, reproduction steps, impact, and any suggested mitigation.

Do not test Internet-Well against repositories, accounts, systems, or data you do not own or have explicit authorization to assess.

## Scope

Security reports may cover the Internet-Well CLI, packaging, workflows, report redaction, consent gates, path handling, and registry integrity. Findings produced about third-party repositories should be reported to the relevant owner through their disclosure process, not published here.

## Product limits

Internet-Well provides preliminary static assessment and planning. It is not a penetration-testing service, vulnerability certification, legal opinion, privacy certification, or production approval.
