# Python Stack Guide

## Detection

Look for Python source, `pyproject.toml`, requirements files, lockfiles, virtual-environment tooling, web frameworks, workers, notebooks, and test configuration.

## Required controls

Pinned dependencies, supported runtime, isolated environments, type and lint strategy, test coverage, input validation, secure serialization, subprocess boundaries, secrets isolation, logging, packaging, and reproducible builds.

## Compatible capabilities

Unit and integration testing, type checking, linting, dependency scanning, secrets detection, SAST, packaging, API testing, performance profiling, sandboxing, and observability.

## Verification

Create a clean environment; install from the lock or declared constraints; run tests, type checks, lint, dependency and secret scans; build the package or image; exercise critical interfaces; and confirm deterministic startup and failure behavior.

## Human review

Code execution, deserialization, ML models, financial calculations, regulated data, production workers, and privileged automation require competent review.
