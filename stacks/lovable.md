# Lovable Stack Guide

## Detection

Look for Lovable project metadata, generated React/Vite code, linked GitHub repository, Supabase integration, Lovable deployment references, and platform-managed environment settings.

## Required controls

GitHub as source-of-truth decision, synchronization ownership, generated-code review, environment and secret separation, Supabase policy verification, dependency pinning, deployment portability, custom-domain ownership, backups, and exit strategy.

## Compatible capabilities

Generated-code review, Git synchronization validation, React testing, Supabase security, dependency scanning, secrets detection, deployment verification, portability review, accessibility, and product audit.

## Verification

Confirm the authoritative codebase; compare deployed state with the intended commit; run tests and production build outside the editor; inspect Supabase policies and secrets; verify domain, deployment, rollback, and portability to an independent host.

## Human review

Production publishing, domain changes, database policies, secrets, billing, authentication, regulated data, and migrations away from the platform require explicit authorization and qualified review.
