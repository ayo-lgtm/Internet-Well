# Vercel Stack Guide

## Detection

Look for Vercel project configuration, deployment URLs, environment references, serverless or edge runtime declarations, cron configuration, analytics, and framework presets.

## Required controls

Environment separation, scoped environment variables, preview protection, production promotion policy, function/runtime limits, domain and redirect ownership, cache behavior, observability, cost controls, rollback, and deployment provenance.

## Compatible capabilities

Deployment verification, preview testing, secrets management, observability, performance monitoring, caching review, domain governance, incident response, cost analysis, and rollback rehearsal.

## Verification

Confirm production and preview environments differ appropriately; inspect build and runtime logs; test critical journeys on a deployment preview; verify headers, redirects, cache behavior, function failures, environment scoping, and rollback.

## Human review

Production domains, billing, environment secrets, authentication, firewall rules, regulated data, and irreversible production changes require explicit authorization and qualified review.
