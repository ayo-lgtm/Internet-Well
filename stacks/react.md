# React Stack Guide

## Detection

Look for React packages, JSX/TSX, component trees, client-side routing, state libraries, build tooling, and browser-oriented tests.

## Required controls

Component boundaries, accessible semantics, input validation, state consistency, error handling, dependency integrity, performance budgets, browser compatibility, testable critical journeys, and secure API interaction.

## Compatible capabilities

Unit and component testing, browser testing, accessibility, visual regression, performance testing, dependency scanning, secrets detection, design systems, analytics validation, and error monitoring.

## Verification

Run type checks, lint, component tests, critical-path browser tests, keyboard and screen-reader checks, accessibility scans, production build, bundle analysis where material, and representative browser verification.

## Human review

Review is required for sensitive forms, authentication flows, payments, regulated disclosures, accessibility conformance claims, and interfaces that materially affect users.
