# Capability Graph

Select capabilities before tools.

## Build and architecture

- product discovery
- requirements and acceptance criteria
- architecture documentation
- API design
- database design and migrations
- dependency and license management
- decision records

## Quality

- unit testing
- integration testing
- browser end-to-end testing
- accessibility testing
- performance testing
- AI evaluation and red teaming
- regression and release verification

## Security and privacy

- threat modeling
- secrets detection
- dependency and container scanning

- authentication and authorization review
- privacy data-flow mapping
- secure configuration
- incident response

## Operations

- deployment and rollback
- monitoring and alerting
- logs and observability
- backup and restore

## Product and business

- user research
- product-value audit
- analytics and measurement
- launch readiness
- marketing operations
- sales and CRM
- finance and bookkeeping
- legal-compliance triage
- decision simulation

## Common bundles

### Web or AI SaaS launch

Architecture documentation + decision records + unit tests + browser tests + accessibility + secrets detection + dependency scanning + privacy review + monitoring + backup/restore + incident response + AI evaluation where applicable.

### Existing product audit

Product-value assessment + critical-journey tests + accessibility + architecture review + security/privacy triage + operations + evidence-backed remediation plan.

### High-impact AI product

Data provenance + prompt-injection controls + model evaluation + abstention/fallback behavior + human review + privacy/security + incident response + domain-expert validation.

## Selection notes

Capabilities may be mandatory even when no registry resource is yet approved. In that case, report the gap and use a standard or supervised procedure rather than pretending the need is covered.
