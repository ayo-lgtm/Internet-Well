# Bundle: Privacy Baseline

## Outcome

Create a minimum defensible privacy and data-governance foundation that matches actual product behavior and can grow with risk.

## Required capabilities

Data inventory, purpose limitation, minimization, consent or permission, access control, provider review, retention, export, correction, deletion, analytics governance, incident response, and accurate disclosures.

## Selection rules

Apply the product and jurisdiction assessment. Select resources that illuminate real data flows and controls. Templates must be adapted to behavior; policy text never substitutes for implementation. Avoid collecting data merely because a tool supports it.

## Implementation order

1. map data and purposes;
2. remove unnecessary collection;
3. control access and providers;
4. define retention and deletion;
5. implement user controls;
6. align notices and contracts;
7. test and monitor.

## Verification

Trace representative records; test consent, withdrawal, export, correction, deletion, closure, analytics, provider calls, access, retention, and backup implications with non-production data.

## Human review

Privacy, legal, security, and records specialists must review regulated data, children, health, finance, biometrics, employment, cross-border transfers, and compliance claims.
