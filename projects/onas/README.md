# ONAS

Habit-building RPG for Nigeria: real-world quests level up a stylized Hero.

| File | Purpose |
|---|---|
| [`SPEC.md`](SPEC.md) | What is built today, phased plan (no money first), architecture, verification tiers |
| [`LEGAL-ISSUES.md`](LEGAL-ISSUES.md) | Counsel register: each money and data feature with its exact flow, open questions, and sign-off |
| [`project-profile.json`](project-profile.json) | Project assessment conforming to `outputs/project-assessment.schema.json` |

Rule: a money feature is built only after its row in `LEGAL-ISSUES.md` is marked Cleared.
